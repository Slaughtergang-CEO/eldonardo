Sicherheit & Struktur

Unsere Qualitäts- & Sicherheitsstandards

Sicherheit und Datenschutz stehen bei uns an erster Stelle. Wir setzen auf bewährte, moderne Datenbanktechnologien von Supabase, um Ihre Kundendaten optimal zu schützen. Mit unserer automatisierten Sicherheits-Validierung garantieren wir, dass sensible Dateien wie Rechnungen oder Buchungsdaten ausschließlich für berechtigte Personen zugänglich sind.

Das Sicherheitskonzept: Die Dateipfade zu n8n-Workflow-Inhalten oder exklusiven Code-Elementen liegen in geschützten Private Buckets. Über Row Level Security (RLS) verifiziert die Datenbank live, ob der anfragende Nutzer einen aktiven Kauf-Eintrag in der Transaktionsdatenbank (purchases) besitzt, bevor der Server den Download gewährt.

SCHEMA: products & purchases
TABLE: products
id: uuid (PK)
title / slug: text
price: numeric
category: text
file_download_path: text
TABLE: purchases
id: uuid (PK)
user_id: uuid (FK)
product_id: uuid (FK)
stripe_session_id: text
ROW LEVEL SECURITY POLICY

Verhindert unbefugte Dateidownloads direkt über den Storage-Bucket auf Dateiebene:

CREATE POLICY "Buyer Validation" ON storage.objects FOR SELECT USING ( bucket_id = 'private_assets' AND EXISTS ( SELECT 1 FROM purchases WHERE user_id = auth.uid() AND product_id = ( SELECT id FROM products WHERE file_download_path = name ) ) );

Fragen & Antworten

Häufig gestellte Fragen

1. Wo werden die KI-Modelle gehostet und sind sie DSGVO-konform?

Ja. Wir nutzen ausschließlich DSGVO-konforme Schnittstellen (APIs). Die Datenverarbeitung erfolgt über Server in europäischen Rechenzentren (Frankfurt am Main). Kundendaten werden nicht zum Training der globalen KI-Modelle verwendet.

2. Entstehen für mich laufende Zusatzkosten für OpenAI oder n8n?

Nein, sofern Sie unsere gehosteten Managed-Optionen wählen. In unseren monatlichen Gebühren sind die API-Nutzungskosten (z. B. GPT-4o Token) bis zu einem großzügigen Fair-Use-Limit bereits vollständig abgedeckt.

3. Was passiert, wenn sich eine API (z. B. WhatsApp oder Stripe) ändert?

Im Rahmen unserer Managed-Tarife umfassend überwachen wir alle Workflows und API-Verbindungen rund um die Uhr. Sollte es zu Updates seitens der Drittanbieter kommen, passen wir den Code im Hintergrund kostenfrei an, damit Ihr Betrieb nahtlos weiterläuft.
